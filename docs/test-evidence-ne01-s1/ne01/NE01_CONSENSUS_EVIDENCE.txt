WHAT WE BUILT

- Canonical encrypted-sector commitments and Merkle openings.
- Checkpointed ratchet sealing tied to sector identity and chunk contents.
- Beacon-sampled audit verification with a pinned audit policy.
- Funded, conserved storage-power accounting with bounded issuance and expiry.
- Eligibility calculated from the intake's own accepted audits and live roots.
- Integration tests covering CWC, bounded DAG ordering and delivery receipts.

WHAT THE REGRESSION TESTS NOW DEFEND

- Forged or edited AuditPass and audit history values cannot be submitted through
  the public Rust API as genuine issued evidence.
- Genesis bookkeeping, outside roots and delivery receipts do not create power.
- Replayed, invalid and mismatched audit responses are rejected.
- A missing audit after a clean run revokes Established in the model.
- Ledger conservation is checked against an independent 2,000-action model.

TECHNICAL SCOPE — RESEARCH, NOT PRODUCTION CERTIFICATION

Established is the NE-01 model result under its documented eight-epoch acceptance
profile. It does not establish production consensus soundness, physically
independent replica storage or a scarce-resource theorem. The current research
sealing profile has no measured storage/time security margin: retaining 1 KiB
of chain finals permits checkpoint regeneration in about 0.0041 seconds against
a five-second laboratory window. Seven production gates remain open, including
external review, multi-device testing, beacon unpredictability, improved delay
and depth robustness, the resource theorem, and hosted CI.
