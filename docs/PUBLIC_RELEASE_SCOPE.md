# Publication scope and disclosure markers

This is an additive update for public baseline
`2e1893647adb1e7db75bad5efc34b7652ed256c1`.
Merge its contents at the existing repository root. Replace same-path files;
retain all other existing files, especially licenses. The included source
manifest is for the complete merged tree, not only this smaller update folder.

## Released

- Existing CWC/verifier/accounting/byte-observation public components, unchanged.
- Small portable information models and separate finite-data checking.
- Deterministic request encodings and generated response-frame test inputs.
- Unit tests, negative controls, reproduction commands and clear result scopes.

## Not released

The complete consensus construction, operational services, private proof/setup
materials, internal source archives, review/handoff notes, execution-environment
records, credentials and runtime data are not part of this export. Selected
public test data do not imply that all research or implementation is open source.

The `blockchain/` directories contain README-only disclosure markers. Their
presence is not evidence of runnable consensus, a node binary, a migration
bridge or a production deployment. The project conducts research in those
areas, but that implementation is not supplied by these directories.

## Safety of publication

The archive contains a selected file allowlist and no Git metadata or workflow.
Its contents and metadata were screened for credential patterns, personal
identifiers, private repository references and internal workspace paths.
This is a package-content check, not a guarantee of anonymity: public code can
be compared with other copies, and the publishing account and commit metadata
remain visible independently of this ZIP.

All inherited third-party copyright/license notices must stay intact. A source
manifest demonstrates byte consistency, not authorship, scientific priority,
license compatibility, security or correct program behavior.

Nothing is uploaded automatically. Publication is a separate repository action.
